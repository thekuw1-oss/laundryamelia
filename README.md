# 🌸 Laundry AM — Website Laundry Pink & Putih Super Menarik ✨

Website aplikasi kasir dan manajemen cucian **Laundry AM** dengan perpaduan warna **pink pastel dan putih bersih**. Tampilan awal (halaman selamat datang) kini dirancang **jauh lebih hidup, interaktif, dan memukau** layaknya website modern profesional namun tetap imut dan menggemaskan (*kawaii*).

---

## 🌟 Tampilan Awal (Halaman Selamat Datang) yang Ditingkatkan

1. **Floating Header Modern**:
   - Menampilkan logo gelembung `🧺 Laundry AM`.
   - Jam operasional dengan indikator lampu hijau berdenyut (`Buka: 07.00 - 21.00 WIB`).
   - Tombol langsung untuk membuka Dashboard.

2. **Dua Kolom Hero Showcase (Split Layout)**:
   - **Sisi Kiri**:
     - Tagline berkilau: `✨ Solusi Laundry Bersih dan Wangi No. 1 🌸`.
     - Judul besar dengan tipografi gradasi pink yang anggun.
     - 3 Kartu Keunggulan: **Harum Sakura 7 Hari**, **Express 5 Jam Jadi**, dan **100% Higienis & Bersih**.
     - Tombol Mulai beranimasi kilau cahaya (*shimmer*) & tombol **Tambah Pesanan Baru**.
     - Badge kepuasan pelanggan `⭐ 4.9/5 dari 1.200+ Pelanggan Setia` dengan garansi cuci ulang.
   - **Sisi Kanan (Panggung Mesin Cuci Kawaii & Interaktif)**:
     - 4 Kartu Melayang (*Floating Badges*) di sekitar mesin cuci.
     - **Mesin Cuci Kawaii Besar**: Memiliki wajah lucu tersenyum, pipi merona, layar LED digital, dan pakaian berputar di dalam drum air.
     - **3 Tombol Interaktif**:
       - 🫧 *Busa Sabun*: Mengeluarkan gelembung sabun melimpah dengan efek suara pop!
       - 🌀 *Putar Kencang*: Mesin cuci bergetar dan berputar lebih kencang!
       - 🌸 *Semprot Parfum*: Efek semprotan bunga sakura harum!

3. **Transisi Mulus ke Dashboard**:
   - Mengklik tombol **"Mulai ke Dashboard"** atau **"Tambah Pesanan Baru"** akan langsung membawa pengguna ke Dashboard kasir secara instan dan mulus.

---

## 🧺 Halaman Dashboard (Pink & Putih Bersih)
- Judul: **Dashboard Laundry AM**.
- **Ringkasan Kartu Cantik**:
  - 🧺 Jumlah Pesanan
  - 🌀 Pesanan Diproses
  - ✨ Pesanan Selesai
- **Menu Sederhana**:
  1. **Dashboard** — Ringkasan & 5 transaksi cucian terbaru.
  2. **Data Pesanan** — Form input cucian (nama, WA, tarif, berat, hitung harga otomatis) dan tabel riwayat lengkap (bisa ubah status, cetak nota thermal, edit, hapus).
  3. **Data Pelanggan** — Daftar pelanggan setia dengan tombol **Chat WhatsApp** langsung.
  4. **Tombol "Halaman Depan"** — Untuk kembali menikmati halaman selamat datang kapan saja.

## 🚀 Cara Menjalankan Website

### Cara 1: Menggunakan Localhost
1. Buka folder `C:\Users\DELL\Documents\laundriku`.
2. Klik 2x file `jalankan_localhost.bat`.
3. Browser otomatis terbuka di:  
   👉 **`http://localhost:3000`**

### Cara 2: Buka Langsung File HTML
1. Klik 2x file `index.html`.
2. Website langsung jalan di browser favorit Anda tanpa memerlukan server.
